# Responsible Use

Website fingerprinting can expose browsing activity despite encrypted
transport. This artifact is released to support reproducible privacy and
traffic-analysis research, including evaluation of defenses.

Use the software only with authorization. Do not monitor third-party users,
collect credentials, evade access controls, or deploy it for surveillance.
Sanitize public traces and manifests so they contain no IP addresses, browser
profiles, Tor keys, cloud credentials, account identifiers, or unrelated
payload data. Follow institutional ethics requirements and all dataset terms.
